# 対話コンソールの契約

各プロセスの出力と画面操作は継承した mux 画面に作用する。画面は 80 列×25 行で、座標は左上を `(0, 0)` とする。`ss9_console_locate(x, y)` はカーソルを移動し、範囲外ではエラーを返す。`ss9_console_clear()` は画面を消去し、カーソルを左上へ戻す。非表示画面への操作はその画面の保存状態を変更し、画面切り替え時に表示へ反映する。IOCS と画面状態の操作は共通ロックで直列化する。

`ss9_console_key()` は非ブロッキングで、キーがなければ -1 を返す。foreground プロセスだけが自身の画面の入力を取得できる。ASCII があるキーは下位 8 bit、ASCII のない特殊キーは IOCS のスキャンコードを上位 8 bit にして返す。Ctrl-C はアプリへ渡さず、シェルの foreground 中断処理へ通知する。入力キューの取り出しと Ctrl-C 監視は直列化する。mux 有効時は F1／F2／F3 で画面 1／2／3 を選ぶ。この3キーはmuxが消費する。

MPX68K の Ctrl 対応検証版で文字・特殊キー、画面消去、座標指定、画面切り替え、Ctrl-C と背景出力を確認した。ユーザーは通常インストール版を入れ替えたと報告したが、入れ替え後の操作と実機動作は未検証。再描画時は物理画面の意図しないスクロールを防ぐため、右下セルを描画しない制限がある。
