# アセンブラ契約 (Phase 3)

更新日: 2026-11-11

SSOS-9 上で動作する MC68000 アセンブラ `asm` (S9M1 アプリ) の構文、対象命令、オブジェクト形式、再配置、エラー処理の契約。Phase 4 のリンカはこのオブジェクト形式を入力とする。

## 対象と上限

- 対象 CPU は MC68000 の整数命令のみ。FPU、MMU、68010 以降の命令は対象外。
- ソースは FAT16 上の 8.3 名ファイル。1 行は 200 byte まで、全体で 1200 行まで。行内に NUL byte が現れた場合は「NUL byte in source line」の診断でエラーとし、NUL で行を黙って打ち切ったり除去したりしない。
- 出力 text セクションは 24576 byte、data セクションは 6144 byte、bss は 65536 byte、シンボル 256 件、再配置 512 件、オブジェクト全体で 65535 byte まで。超過時はエラーで停止する。モジュールは静的領域を持てないため、作業領域はすべてスタック上に確保する。
- entry は text 先頭 (offset 0) に固定。

## 構文

- 行は `[label:] [命令|疑似命令 [引数]] [;コメント]`。コメントは `;` から行末まで。
- ラベルは先頭の識別子に `:` を付ける。識別子は英字または `_` 開始で英数字と `_`、長さ 1～31。
- 数値ラベル `0:` ～ `9:` は何度でも定義できる。参照 `Nb` は現在行より前の直近定義、`Nf` は現在行より後の直近定義。判定は 2 パス目で行う。
- レジスタは `%d0`～`%d7`、`%a0`～`%a7`、`%sp` (=`%a7`)、`%pc`、`%ccr`、`%sr`、`%usp`。`%fp` は使わない。
- サイズ接尾辞は `.b` `.w` `.l`。分岐は `.b` (または `.s`) と `.w`。
- 即値は `#式`。文字定数 `'a` は値 65 として扱う。閉じ形式 `'a'` も受理し、閉じ引用符は読み飛ばす(`#'a', %d0` は 97 とその後のカンマに字句解析される)。契約の基本形は閉じない `'a` のまま。
- 数値は 10 進 `123`、16 進 `$FC` または `0xFC`。2 進・8 進リテラルは対象外。32 bit に収まらない数値リテラルは「範囲」エラー (GAS も拒否する)。
- 式は `+ - * / & | ^ ~ << >>` と括弧、単項 `-` `~`、位置カウンタ `.`。優先順位は GAS 実測に従う: `* / << >>` は同レベル (左結合) > `+ -` > `&` > `^` > `|` (C とは異なり `*` と `<<` は同レベル)。演算は 32 bit 符号付きで、`/` はゼロ切り捨て。シフト量は 0～31、シフト量 0 は 1 として扱う。除数 0 は「範囲」エラー。除数 -1 は `-x` と定義し、`INT_MIN / -1` は `INT_MIN`(2 の補数の折り返し)とする(ターゲットではトラップ、ホストでは未定義動作になるため契約で定義)。単項 `-` の `INT_MIN` も同じ折り返しとする。剰余演算子は文法に存在しない。
- レジスタリスト (`movem`) は `%d0-%d3/%a0` 形式。範囲と単一を `/` で連結する。

## アドレッシングモード

| 書式 | モード |
| --- | --- |
| `%dn`, `%an` | データ/アドレスレジスタ直接 |
| `(%an)`, `(%pc)` | 間接 (PC 間接は `d16(%pc)` と同一視) |
| `(%an)+`, `-(%an)` | ポストインクリメント / プリデクリメント |
| `d16(%an)`, `d16(%pc)` | 16 bit 変位 |
| `(d16,%an)`, `(d16,%pc)`, `(d8,%an,%xn)`, `(d8,%pc,%xn)` | 括弧内変位形式 (GAS 表記)。上の行と同じ意味で受理する |
| `d8(%an,%xn.l)`, `d8(%an,%xn.w)`, `d8(%pc,%xn.l)` | 簡略インデックス形式。`%xn` は `%d0`～`%d7`/`%a0`～`%a7`。サイズ省略時は `.l` |
| `expr` / `expr.w` / `expr.l` | 絶対アドレス。サイズ省略時は `.l` |
| `#expr` | 即値 |

## 命令一覧

MC68000 整数命令のうち、次をサポートする。

- 転送: `move` (`.b/.w/.l`、`move %xx,%ccr/%sr/%usp` を含む。`%ccr` からの読み出しは 68010+ のため対象外で、GAS -m68000 も拒否する)、`movea`、`moveq`、`movem`、`movep`、`lea`、`pea`、`clr`、`exg`、`swap`、`ext`、`link`、`unlink` (GAS 表記 `unlk` も受理)
- 算術論理: `add` `adda` `addi` `addq` `sub` `suba` `subi` `subq` `and` `andi` `or` `ori` `eor` `eori` `cmp` `cmpa` `cmpi` `cmpm` `muls` `mulu` `divs` `divu` `neg` `negx` `not` `abcd` `sbcd` `nbcd` `tas` `chk`
- シフト回転: `asl` `asr` `lsl` `lsr` `rol` `ror` `roxl` `roxr` (即値、レジスタカウント、メモリ形式)
- ビット操作: `bset` `bclr` `bchg` `btst` (即値番号とレジスタ番号)
- 分岐ジャンプ: `bra` `bsr` と 14 条件 `bcc bcs beq bge bgt bhi ble bls blt bmi bne bpl bvc bvs`、`dbcc` 系は同じ 14 条件と `dbra`、`jmp` `jsr`、`scc` 系は同じ 14 条件
- 特権・その他: `rte` `rts` `rtr` `nop` `stop` `reset` `trap` `trapv` `tst` `illegal`

未サポートの命令、FPU 命令、`bt`/`bf`/`dbt`/`st`/`sf` は「不明な命令」エラーで拒否し、黙って受理しない。ニーモニック表にこれらの名前はないため、表に存在する命令の未対応形式とはエラー種別が異なる。

### 解釈の規則

- サイズ接尾辞の規則は命令グループごとに次の通り。表中の「必須」は省略時エラー、「不要」は付与時エラー。

| グループ | 命令 | 接尾辞 |
| --- | --- | --- |
| バイト/ワード/ロング | `move` `add` `addi` `addq` `sub` `subi` `subq` `and` `andi` `or` `ori` `eor` `eori` `cmp` `cmpi` `cmpm` `neg` `negx` `not` `clr` `tst` | `.b/.w/.l` 必須 |
| シフト回転 | `asl` `asr` `lsl` `lsr` `rol` `ror` `roxl` `roxr` | `.b/.w/.l` 省略可 (省略時 `.w`)。メモリ形式は常にワード |
| ワード/ロング | `movea` `movem` `movep` `adda` `suba` `cmpa` `ext` | `.w/.l` 必須 |
| ワード固定 | `muls` `mulu` `divs` `divu` | `.w` 必須 |
| ワード固定 | `chk` | `.w` 必須。`chk.l` は 68020+ で対象外 (GAS -m68000 も拒否) |
| バイト固定 | `tas` `abcd` `sbcd` `nbcd` `bset` `bclr` `bchg` `btst` | `.b` 省略可 (省略時 `.b`)。GAS が拒否する `abcd.b` 等も受理する (受理集合のスーパセット) |
| ロング固定 | `swap` | 接尾辞不可 |
| セット条件 | `scc` 系 14 条件 | `.b` 省略可 (省略時 `.b`) |
| 分岐 | `bra` `bsr`、`bcc` 系 14 条件 | `.b`/`.s`/`.w` 省略可 (省略時 `.w`) |
| DBcc | `dbcc` 系 14 条件と `dbra` | `.w` 省略可 (変位は 2 バイト固定) |
| サイズなし | 上記以外すべて (`lea` `pea` `moveq` `exg` `link` `jmp` `jsr` `rte` `rts` 等) | 接尾辞不要 |

- `add` `sub` `and` `or` `eor` `cmp` は即値ソースを拒否する。`addi` 等の明示形式か `addq`/`subq` (`#1`～`#8`) を使う。
- 分岐の `.b`/`.s` は 8 bit 変位で、同一 text セクション内の解決済み目標のみ。外部シンボルまたは別セクションへの `.b` はエラー。
- 絶対アドレス指定のサイズ省略時は `.l`。値に依存するサイズ決定と緩和は行わない。
- `movem` のプリデクリメント形式では、エンコード上のマスクビットを反転して登録する (論理的な並びで書かせ、メモリ並びに変換する)。
- `exg` は対称命令のため、`%an,%dn` の並びは GAS と同じ `dn,an` 形式に正規化して符号化する (`exg %a0,%d0` は `exg %d0,%a0` と同一のバイト列)。
- 位置カウンタ `.` は `even` 疑似命令で偶数化される前の現在値。

## 疑似命令

| 疑似命令 | 意味 |
| --- | --- |
| `.text` `.data` `.bss` | 現在セクションを切り替える |
| `.globl name` | シンボルを公開する |
| `.extern name` | 外部シンボルを宣言する |
| `.equ name,expr` | 絶対値シンボルを定義する。前方参照は不可 |
| `.byte e1,...` / `.dc.b` | 各式を 1 byte で発行 (1 行 8 式まで) |
| `.word e1,...` / `.dc.w` | 各式を 2 byte で発行 |
| `.long e1,...` / `.dc.l` | 各式を 4 byte で発行 |
| `.space expr` / `.ds.b/.w/.l expr` | 現在セクションに穴を空ける。`.bss` では値 0 の領域として扱う。`expr` は前方参照不可 |
| `.even` | 次の発行位置を偶数に揃える |
| `.ascii "s"` `.asciz "s"` | 文字列。`.asciz` は NUL を追加。エスケープは `\n \t \r \\ \" \0` |
| `.end` | 以降の行を無視する |

マクロ、条件アセンブル、`.include`、繰り返しは対象外。未対応の疑似命令はエラーで拒否する。

命令と 2/4 バイトデータ (`.word`/`.dc.w`、`.long`/`.dc.l`) は偶数オフセットに置かなければならない(奇数アドレスは実行時/読み取り時にアドレスエラーになるため)。パス 1 で奇数オフセットへの発行を検出した場合は「odd offset」エラーで停止する。自動整列は行わない(サイレントなサイズ変動を避ける)。整列には `.even` を使う。`.byte` と文字列はバイト単位のため任意の位置に置ける。

## 2 パス処理

1 パス目はラベル定義と各文のサイズ確定のみを行う。サイズは構文のみから定まり、シンボル値に依存しない。2 パス目はバイト列の発行と再配置の生成を行う。パス間でサイズが変わる書式 (値依存の緩和) は存在しない。

## 再配置

同一 text セクション内への PC 相対分岐はアセンブル時に解決し、再配置を発行しない。次の場合に再配置を発行する。

| 種類 | 値 | 発行条件と意味 |
| --- | --- | --- |
| `PC16` | 1 | `.w` 分岐または `d16(%pc)` が外部シンボルまたは別セクションを参照する。値は `S + A - P` |
| `ABS32` | 2 | `.long`、`.l` 絶対、`.l` 即値 `#シンボル` など 32 bit 幅への相対/外部参照 |
| `ABS16` | 3 | `.word`、`.w` 絶対、`.w` 即値、`d16(%an)` の変位への相対/外部参照 |
| `ABS8` | 4 | `.byte`、`.b` 即値 `#シンボル` への相対/外部参照。オフセットは値バイト (16 bit 語内の下位バイト) 位置 |

再配置位置のバイト列は、セクション相対の解決済み値 (セクション先頭からのオフセットに定数を加えた値) を書く。外部シンボル参照の場合は 0 を書く。`S` はシンボルのセクション先頭からの値、`A` は式の定数部分、`P` はフィールドのセクション内オフセット。PC16 の `P` は拡張語アドレスであり、MC68000 が PC 相対変位の基準に使う実行時 PC もこの拡張語アドレスに一致する (`bra.w` を GAS でアセンブルしてリンクした実測: reloc は offset=P、addend=0 で、パッチ値は `S - P`)。

`d16(%pc)` の変位に絶対値式 (数値や `.equ` のシンボル) を書いた場合は再配置を発行せず、その値をリテラル変位として書く。数値変位は GAS もアセンブル時に同じバイト列へ解決する (実測: `move.w (4,%pc),%d3` は GAS もフィールド `0004`、再配置なし)。

分岐 (`bra`/`bsr`/`bcc` 系、`dbcc` 系を除く) のオペランドに数値や `.equ` の絶対シンボルを書いた場合は、その値を変位フィールドにそのまま書く (実行ターゲット = 拡張語の次のアドレス + 変位)。これは GAS との意図的な差異である: GAS は数値分岐オペランドを「絶対アドレス」と解釈し、フィールド 0 と `R_68K_PC16 *ABS*+N` (8 bit 幅では `R_68K_PC8 *ABS*+N`) を発行してリンク時に `S + A - P` で折り畳む。最終変位はリンクアドレスに依存し (binutils 2.46 実測: `bsr.w 0x10` を offset 0 に置いてリンクすると `6100 000e`、0x2000 に置くと `6100 e00e`)、PIC モデルの S9O1 ではモジュールの実行時絶対アドレスを知り得ないためこの意味は表現できない。よって数値分岐オペランドの GAS とのバイト一致は契約外とし、リテラル変位がこの契約の意味である。ラベル参照 (同一 text セクション) は従来どおりアセンブル時に解決し、GAS とバイト一致する。

簡略インデックス形式 `d8(%pc,%xn)` と `d8(%an,%xn)` の変位は絶対式 (数値) を書く。`d8(%pc,%xn)` のシンボル変位のうち、同一 text セクション内のシンボルはアセンブル時に拡張語位置からの変位へ解決して受理し (8 bit に収まらない場合は範囲エラー)、外部シンボルと別セクションのシンボルのみ「絶対式でない」エラーとする。`d8(%pc,%xn)` にシンボル変位を書くと GAS は R_68K_PC8 を発行するが、S9O1 には 8 bit PC 相対再配置がなく、簡略インデックス拡張語への PC16 パッチはインデックス指定ビットを壊す。`d8(%an,%xn)` は An 基準のため PC 相対再配置の意味を持たず、シンボル変位は「絶対式でない」エラーとする (`d16(%an)` の変位は ABS16 を発行する)。

text/data 間の参照には ABS32/ABS16 を発行する。PIC 制約は Phase 4 のリンカが診断する。

## オブジェクト形式 S9O1

ビッグエンディアン固定。全体を 65535 byte 以下とする。

```text
offset size field
0      4    magic "S9O1"
4      2    version = 1
6      2    flags = 0
8      4    text_size
12     4    data_size
16     4    bss_size
20     4    entry (常に 0)
24     4    symbol_count
28     4    reloc_count
32     4    name_pool_size
36     4    reserved (0)
40     -    text バイト列
       -    data バイト列
       -    シンボル (12 byte/件): u32 name_offset, u8 section, u8 flags, u16 reserved, u32 value
       -    再配置 (16 byte/件): u32 offset, u32 symbol, i32 addend, u8 section, u8 type, u16 reserved
       -    名前プール (NUL 終端名の連結)
```

- section: 0=abs、1=text、2=data、3=bss、0xFF=未定義 (外部参照)。
- flags: bit0 = グローバル公開、bit1 = 外部宣言、bit2 (0x04) = セクションアンカー。通常のローカルシンボルも表に出す (リンカの診断用)。
- セクションアンカーは予約名 `\001text` / `\001data` / `\001bss` (先頭に 1 byte の 0x01) で、section 1/2/3、value 0、flags bit2。アセンブラが相対/外部参照の再配置をこのシンボルに対して発行する。`` で始まる名はユーザー識別子として書けないため衝突しない。リンカはセクション相対参照をこのシンボルの値 (0) に解決する。
- value: 定義シンボルはセクション先頭からのオフセット、`.equ` は絶対値、外部は 0。
- 名前プールの重複除去は必須としない。

## エラー処理

- 最初のエラーで停止し、`FILE:行番号: メッセージ` を診断出力に書いて終了コード 1 で終わる (ターゲットの `asm` はコンソール出力、ホスト検証ドライバは stderr)。オブジェクトは出力しない。ラベルと `.equ` の再定義は、同一パス内では同じ値への再定義も含めて「シンボル二重定義」エラー。パスをまたぐ再定義は、パス 1 とパス 2 が同じセクションの同じ位置に定義する場合のみ許可する。
- エラーメッセージは種別ごとに固定文字列とする。不明な命令、未対応命令、未対応疑似命令、構文、シンボル二重定義、未定義 (2 パス目で解決できない参照)、範囲、領域超過を区別する。
- `.globl` は定義より前にも書ける。2 パス目の終了時に解決し、その時点で未定義ならエラーとする。前方宣言 (未解決のまま保持するもの) は 64 件まで。
- 警告 (処理を停止しない、オブジェクトのバイト列は不変): `.text` 内の `.word`/`.dc.w` にシンボル相対または外部参照を書くと ABS16 再配置になるが、PIC モデルではこの語は実行時に A5 変位として読まれる。書いた意図 (絶対値定数) と実行意味が食い違うため、行番号付きの警告を出す。出力先はホストドライバでは stderr、ターゲットの `asm` ではコンソール。
- 出力ファイルの書き込みに失敗した場合はエラーを報告する。ファイル削除の syscall はないため、不完全な出力ファイルが残る可能性がある。

## CLI

`run asm SRC [DST]`。`SRC` はアセンブル対象、`DST` 省略時は `SRC` の拡張子を `.O` に置き換えた名前。導出結果の base にドットが残る場合 (`A.B.C` → `A.B` など) は 8.3 名にならないため、拡張子なし扱いにはせず「名前」エラーで拒否する。`DST` が既存の場合は置き換える。

## 検証

- ホスト単体試験: 字句解析、構文解析、式評価、エンコードの既知ベクトル、オブジェクト出力。
- クロスツールチェーン比較: 同一ソースを `m68k-xelf-as` と比較し、text バイト列の一致を確認する。比較時は GAS 側の定義済み (セクション) シンボルへの再配置を、この契約のフィールド規則 (解決済み値) に合わせてバイトへ折り畳む。数値分岐オペランドは GAS とバイト一致しないため (前述)、golden ケースには含めず単体試験でリテラル変位を固定する。実測に基づく GAS (binutils 2.46 m68k) の制限として、16 進 `$` 定数は未定義シンボル化されてリンク不能になり、前方参照の `.s`/`.b` 分岐は受理されないため、正例は `0x` 表記と後方 `.s`/`.b` 分岐のみを使用する。
- QEMU 統合試験: 実 S9M1 `asm` を FAT16 上のソースに対して実行し、出力オブジェクトをホスト実行結果と byte 単位で比較する。
