# Human68k 形式 SCSI HDD 対応計画

状態: 実装途中。Human68k の SCSI 管理情報・BPB を検査する独立関数を追加し、
合成媒体の unit / QEMU テストを追加した。既存の `smount` はまだその関数を使わず、
現行の MS-DOS 型 FAT16 のままであり、この仕様を満たさない。

## 対象

SSOS-9 から X68000 / Human68k 形式の SCSI HDD 上のファイルを読み書きする。
既存の MS-DOS 型 FAT16 ボリュームのサポートは廃止し、`smount` とファイル API を
Human68k 形式へ移行する。Human68k 形式も FAT を使うため、FAT という方式そのものは
廃止しない。2HD の既存読み取り専用 FAT12 module loader は HDD 機能と別に維持する。

Human68k HDD は PC の MBR や BPB のレイアウトを前提にせず、X68000 のデバイス・
パーティション管理情報と該当パーティションの管理情報を検証する。セクタと
物理ブロックの単位を混同しない。SCSI HDD の管理情報は 1024 byte 単位であり、
物理ブロックが 512 byte の場合は 2 ブロックを組み合わせる。その他の物理ブロック
サイズは実装・テストで検証したものだけを受け付け、未対応形式を拒否する。

Human68k のファイル名は最大 18+3 バイトで Shift-JIS を含み得る。まず既存アプリが
扱う ASCII 名と `A:\TEST\NAME.EXT` のようなディレクトリ付きパスを実装する。
18+3 バイトの名前と Shift-JIS は文字境界・比較規則・禁止文字を資料と試験で確定し、
正しく扱えるようになってから対応とする。未対応名を短縮・変換して別名にしない。

16 bit FAT の幅だけで PC 形式と互換だと判断しない。Human68k 標準の 2 byte FAT と
Intel 配列の FAT の区別、管理情報のバイト順、未使用の第 2 FAT の扱いは、媒体の
種類と Human68k の仕様に従い判定する。現行の MS-DOS BPB 解析と FAT 複製一致条件を
そのまま流用しない。対応できない形式は書込み前に拒否する。

## ファイル操作

- SCSI 容量・パーティション範囲・全てのブロック変換を検証してからマウントする。
- ディレクトリの走査はルートから行い、各要素がディレクトリか通常ファイルかを検証する。
  `..` やルート外への脱出、パーティション外アクセスを拒否する。
- 新規作成、既存ファイルの置換、逐次読み書き、close、プロセス終了時の回収を維持する。
  書込みエラー時は既存と同様に以後の書込みを停止し、検査が必要な状態を報告する。
- 作成・置換は使用中のクラスタを破壊しないよう割当と参照を検証する。共有 FAT、
  ディレクトリ項目、データの更新順序と中断時の状態を明示して故障注入で確認する。
- `.x` と `.xdf` の両起動形態を維持する。Human68k の DOS 呼出し経由ではなく、
  既存の SCSI IOCS と SSOS-9 側のファイルシステムを使う。

## 既接続 A: でのテスト制約

Human68k 上の `A:\TEST` 内だけをテスト対象とする。初回にディレクトリを作成する
場合は親ディレクトリにその項目を作る必要があり、ファイルの作成・変更にはディスク
共通の FAT・割当管理情報も更新される。これはディレクトリ内への書込みに伴う
ファイルシステムの管理更新であり、他のユーザーファイルを変更することは許可しない。
既存の `A:\TEST` の内容は事前に確認し、既存名を上書きせず衝突しない新しい名前を
使用する。`A:\TEST` 外のファイル、ini、ディスク構成は変更しない。

実 HDD の書込みに先立ち、独立した合成媒体で正常系・破損・境界・故障注入を試験する。
Human68k 上で作成したテストファイルと SSOS-9 が作成したファイルを相互に読み戻し、
テスト前後の対象外ファイルとディレクトリの内容を比較する。Human68k のキャッシュが
あるため、同時に書き手が存在しない運用と可視性の確認方法を確立してから実 HDD で
検証する。どの論理ドライブがどの SCSI ID・パーティションに対応するかは読み取り
専用で確認し、推測しない。

`A:\TEST` に同名ファイルがある場合は自動削除や上書きをしない。障害時は書込みを
直ちに停止し、修復・再フォーマットを自動実行しない。実機に相当する XEiJ 検証と
物理 X68000 の検証は分けて報告する。
